# 口袋小猫 · Android Desktop Pet

安卓手机上的悬浮桌面宠物原型，支持 Android 8.0 及以上。

## v0.2.0：减少遮挡
- 默认宽度从 120dp 缩小到 80dp，大小可在 56–120dp 之间调节并保存。
- 去掉文字气泡及顶部空白触摸区域；摸摸小猫时用胸前爱心回应。
- 拖动松手自动靠近左右边缘，保存边缘方向和高度；旋转屏幕后重新限制位置。
- 点击小猫打开菜单：摸摸、更小、更大、收起、设置、关闭。
- 收起为边缘 40×48dp 爪印按钮，点击展开，长按仍可打开菜单，也能拖动。
- 设置页提供滑块、收起、展开、恢复默认大小。
- 补充尾巴曲线、腹部、胡须、眼睛高光与爪子细节。
- 收起或屏幕关闭时停止重绘动画；权限检查每秒继续执行。

## 功能
- 原创绘制小猫，眨眼与轻微呼吸动画。
- 拖动移动并自动贴边，点击或长按打开快捷菜单。
- 应用内或通知栏一键关闭。
- 不申请网络、相册、联系人、麦克风等权限。

## 手机下载安装
1. 打开仓库的 Actions，选择最新的 Build Android APK。
2. 等待任务显示绿色成功标记。
3. 打开该次运行，在 Artifacts 中下载 pocket-cat-v0.2.0-apk。
4. 解压 ZIP，点击 app-debug.apk，根据手机提示允许当前来源安装。
5. 打开「口袋小猫」，点击「允许悬浮显示」，授权后返回，再点「召唤小猫」。
6. 按主页键返回桌面；拖动小猫调整位置。

GitHub 的下载界面可能需要通过手机浏览器登录访问。
这是开发测试版 APK，不是应用商店发行版。不同云端构建的调试签名可能不同；若提示签名冲突，请先卸载旧版再安装（位置设置会清除）。

## 构建
JDK 17、Gradle 8.11.1、Android SDK 35。
运行 `gradle :app:assembleDebug :app:testDebugUnitTest :app:lintDebug`。
本项目使用 GitHub Actions 安装固定版本 Gradle，不包含 Gradle Wrapper。

## 权限与限制
悬浮窗用于显示小猫；前台服务及通知用于保持运行、提供关闭入口。
未授权悬浮窗时不会启动宠物；关闭后服务和动画停止，不会自动开机启动。
系统省电策略可能停止服务；锁屏及部分禁止悬浮窗的页面可能不显示。
此版本需要真实手机验证悬浮窗、通知、横竖屏与后台行为，云端编译通过不代表已完成真机测试。

## 验证
云端运行 6 个位置与尺寸边界测试、Android Lint 和 APK 编译。

旋转屏幕；屏幕熄灭再亮起；撤销悬浮窗权限；重启应用后的设置保留。
