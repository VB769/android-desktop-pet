# 口袋小猫 · Android Desktop Pet

Android 8.0 及以上的离线悬浮桌面宠物。当前版本：0.4.1。

## 0.4.1：动作图整改
- 根据用户提供的 12 格白发猫耳角色图整理动作素材，修正跳跃时的鞋子轮廓。
- 每帧按脚部中心与落脚线定位，避免尾巴伸向不同方向时带动整个角色横移。
- 蹲下阶段保持落地，腾空阶段抬高，落地后再蹲下；动作不改变悬浮窗坐标。
- 验证覆盖全部 12 张姿态帧，检查绿色背景过滤、边界裁切与姿态差异。

## 0.4.0：参考图①的白发猫耳 Q 版角色
- 换成白发蓝眼、猫耳与尾巴、黑白服装、粉色蝴蝶结的两头身角色。
- 使用 12 张姿态帧，每个状态两帧：待机眨眼、挥爪、跳跃、伸懒腰、打盹、开心。
- 保留冒字、短按互动、长按菜单、自由位置与可选贴边。
- 图像生成器没有提供透明 alpha，因此原始素材使用纯绿底；应用在首次加载时过滤底色，缓存透明绘制结果，不在每一帧重复处理。
- 两帧姿态切换搭配位置/旋转动画，不是骨骼动画。
- 安装后应用名称仍为「口袋小猫」。

## 0.3.1：Q 版团子小猫
- 加大圆脸和眼睛、缩短身体和四肢、缩小耳朵，改用圆润脸颊与粉色腮红。
- 短爪、短卷尾、薄荷色小项圈与铃铛；挥爪和伸懒腰同步适配新比例。
- 保留自由摆放、气泡台词和全部五种动作。

## 0.3.0 更新
- 修复强制贴边：默认自由摆放，可以停在屏幕中间。保存横纵坐标，重新召唤仍保留位置。
- 自动贴边改为可选开关，默认关闭。收起时靠边，展开后恢复原来的位置。
- 短按小猫：冒出内置台词并执行动作；长按：打开动作和设置菜单。
- 五种动作：挥爪、连续小跳、伸懒腰、打盹、开心摇尾。动作在原地执行，不改变停留位置。
- 每隔约 25 秒的空闲时间自动表演一个动作；可在设置中关闭。
- 奶油白与淡紫配色，重新绘制圆耳、脸颊毛、眼睛、薄荷色围巾和星形挂饰。
- 气泡独立显示 2.6–4.5 秒后消失，靠近顶部时改到下方；不抢输入焦点。
- 保留大小滑块（56–120dp）、边缘收起、通知栏和应用内关闭。
- 屏幕关闭或收起时停止动作重绘。动画期间约 30 帧/秒，静止时约 10 帧/秒；实际效果取决于设备。

## 手机下载
1. 在仓库进入「操作 / Actions」，打开最新绿色成功记录的总览。
2. GitHub App 上点击「项目」下的构建产物数量；网页版查找 Artifacts。
3. 下载 **pocket-cat-v0.4.1-apk**，解压 ZIP，安装 **app-debug.apk**。
4. 下载构建产物需要在打开链接的浏览器中登录 GitHub，App 登录不会自动登录浏览器。
5. 打开「口袋小猫」，允许悬浮显示，再点「召唤小猫」。
6. 默认可自由拖动；短按互动，长按选择动作、收起、设置或关闭。

这是开发测试版，云端调试签名可能随构建改变。如果系统提示签名冲突，先卸载旧版再安装；卸载会清除位置及偏好。不要关闭系统安全检查来解决安装问题。

## 构建和验证
JDK 17、Gradle 8.11.1、Android SDK 35。
运行：
```
gradle :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
```
通过 GitHub Actions 安装固定版本 Gradle，未包含 Gradle Wrapper。
测试包括：自由位置与可选贴边、缩放边界、气泡上下定位、动作开始/打断/结束、拖动中心与重启位置、收起恢复、点击冒字，以及动作绘制预览和裁切检查。
Robolectric 图形预览和测试报告位于 **check-reports** 构建产物。
Robolectric 不能替代真机验证：请检查长按菜单、横竖屏、输入法、后台、屏幕开关和不同系统悬浮权限。

## 权限与限制
没有网络、相册、联系人或录音权限，台词为内置文本。
悬浮窗显示宠物，前台服务和通知提供持续运行及关闭入口。
未授权不会显示；不会自动开机启动。省电策略可能关闭服务，部分应用会禁止悬浮显示。
