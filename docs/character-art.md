## Runtime preparation and registration

Android removes the green matte once on resource loading and caches the result. White hair, cream clothing and blue eyes remain opaque. No image processing runs on each animation tick. The source is opaque and should not be used directly as a transparent PNG.

Columns are equal quarters. Row boundaries are 0, 374, 738, 1086; the authored feet cross an exact one-third boundary. Each frame is trimmed to visible pixels, uses a shared scale, and aligns to baseline 147 in a 160-unit canvas. Foot anchors are manually checked in the source; the jumping pose uses the midpoint of both shoes. Existing jump timing keeps the crouch on the baseline. Screen position, drag persistence and bubble positioning are independent of the artwork.

The application uses two authored poses per state plus translation/rotation, not skeletal animation. Pose proportions may vary slightly. Render tests export all 12 frames at large and small sizes for visual review and check clipping, background transparency and distinct poses.
